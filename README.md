# Portfolio Irénée Mahutin ATISSOUSSI - V13 complète

Cette version a été reconstruite à partir de l'archive V10 complète afin de conserver tous les fichiers CSS, JavaScript et assets.

Projets présents :
1. Messagerie Openfire + OpenLDAP
2. Serveur DHCP + DHCP Relay
3. VPN MPLS Hub-and-Spoke
4. Détection et réponse aux attaques SIP
5. Sécurisation inter-sites avec GETVPN
6. Architecture Cloud AWS - SmartSchool
7. Streaming adaptatif HLS
8. Architecture VoIP/ToIP, QoS et interopérabilité Asterisk

L'ancienne étude NFV/SDN/5G a été supprimée et remplacée uniquement par le projet VoIP/ToIP.

Pour ouvrir le portfolio :
- extraire complètement le ZIP
- ouvrir ensuite index.html
- ne pas déplacer index.html seul, car il dépend des dossiers css, js et assets
